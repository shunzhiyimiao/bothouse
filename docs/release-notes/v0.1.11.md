## Highlights

- **Updates finish on slow connections.** A download now fails only when no new data arrives for 60 seconds, instead of being cut off after a fixed 5 minutes. The 43 MB macOS package no longer times out on a slow link.
- **Clearer update errors.** When every download source fails, the error lists each source with its own cause, so a timeout is no longer hidden behind a later "not found".
- **The updater asks only for files a release actually has.** It requests the package for your platform and `SHA256SUMS`, and no longer tries old file names that no release publishes.
- **Timers can join a running turn.** A timer created with `--inject-if-busy` (API `inject_if_busy`) is folded into the turn that is already running instead of waiting behind it. Off by default.
- **Setup recommends a jev for teams.** With two or more roles and no usable jev, the setup wizard suggests adding one (a free small model is enough), so unaddressed messages do not all go to one role.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. On a slow connection, the one-click update from v0.1.10 or earlier can still time out (the old updater is the one that downloads); if it does, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **慢网下也能更新完。** 下载改为 60 秒内没有收到新数据才算失败，不再固定 5 分钟就掐断。43 MB 的 macOS 安装包在慢网下不再超时。
- **更新出错时说清原因。** 所有下载地址都失败时，错误里逐个列出每个地址和各自的原因，超时不会再被后面的「找不到」盖掉。
- **更新只请求版本里真有的文件。** 只下载本平台的安装包和 `SHA256SUMS`，不再尝试任何版本都没有发布过的旧文件名。
- **定时任务可以并入正在跑的一轮。** 用 `--inject-if-busy`（API `inject_if_busy`）建的定时任务，到点时如果会话正忙，会并进当前这一轮，不再排在后面等。默认关闭。
- **团队配置时推荐 jev。** 有两个及以上角色、又没有可用的 jev 时，配置向导会建议加一个（免费小模型就够），避免没点名的消息全落到同一个角色。

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）（`chmod +x` 后运行）
- **校验：** `SHA256SUMS`

从 v0.1.6 起，以后的版本点左下角「更新到 vX」即可一键更新；v0.1.5 及更早的版本需要先手动下载安装这一版。网速慢时，从 v0.1.10 及更早版本一键更新仍可能超时（下载用的是旧版自带的更新程序）；遇到这种情况，请手动下载安装这一版一次。

安装包未签名。macOS 将 **Bothouse.app** 拖入 Applications，**首次打开请「右键→打开」**；Windows 若弹出 SmartScreen 提示，点「更多信息→仍要运行」。
