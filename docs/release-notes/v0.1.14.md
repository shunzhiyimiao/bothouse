### Fixes

- **Task board shows each chat channel's own name.** On the DSH channel page, the chat channel's block on the task board is headed with that channel's name instead of a fixed "Chat channel", so with several chat channels you can tell which one a task came from.
- **Finished tasks leave "In progress".** When a DSH member or a local CLI member hands a task back, or a bridge bot's task card ends, the task no longer stays counted as in progress on the task board.

### Other

- Self-hosted channel regression test closes the DSH first-run dialogs before it opens Channels (#273).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. On a slow connection, the one-click update from v0.1.10 or earlier can still time out (the old updater is the one that downloads); if it does, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

### 缺陷修复

- **任务板显示聊天频道自己的名字。** DSH 频道页任务板上，聊天频道那一块的标题改为该频道的名字，不再一律叫「聊天频道」；有多个聊天频道时能看出任务来自哪个频道。
- **做完的任务从「进行中」下掉。** DSH 成员或本机 CLI 成员交回任务、或桥接 bot 的任务卡结束后，任务板不再把它算作进行中。

### 其他

- 自建频道回归测试在点「频道」前先关掉 DSH 首启引导弹窗（#273）。
