## Highlights

- **Progress cards for DSH and local CLI members.** In a DSH channel, a DSH member or a local CLI member (Codex, Claude Code and others) now posts the same live progress card that bridge bots post: status, step count, elapsed time, with detailed and short views. The card appears at the member's first tool call and updates in place.

### Fixes

- **DSH settings are back with the channel plugin installed.** The channel plugin no longer takes over a slot that belongs to the DSH settings shell, so settings, the account entry in the sidebar footer, Cmd+,, the connection state and the update badge show again. The model setup dialog in the channel page now points to Settings → Models.
- **Login page shows the version.** The login page shows which bothouse version is running.
- **Chat list card footer.** On the chat page, the session count and time on a project card stay on one line.

### Improvements

- **bothouse name everywhere.** Command help and the install scripts use the bothouse name. The installers read `BOTHOUSE_VERSION` / `BOTHOUSE_REPO`; the old variable names still work.
- **One wording for first open.** The README and the getting-started guide use the same steps for opening the unsigned package the first time on macOS and Windows.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. On a slow connection, the one-click update from v0.1.10 or earlier can still time out (the old updater is the one that downloads); if it does, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **DSH 成员和本机 CLI 成员也有进度卡。** 在 DSH 频道里，DSH 成员和本机 CLI 成员（Codex、Claude Code 等）现在会发出和桥接 bot 一样的实时进度卡：状态、步数、用时，可切换细节和简略视图。成员第一次调用工具时出卡，之后原地更新。

### 缺陷修复

- **装了频道插件后 DSH 设置回来了。** 频道插件不再占用 DSH 设置外壳的插槽，设置页、底栏账号入口、⌘,、连接状态和更新徽标都恢复显示。频道页里的模型配置弹窗改为指向「设置 → 模型」。
- **登录页显示版本号。** 登录页显示正在运行的 bothouse 版本。
- **对话列表卡片底栏。** 对话页项目卡片底部的会话数和时间排在同一行。

### 改进

- **统一叫 bothouse。** 命令帮助和安装脚本统一使用 bothouse 的名字；安装脚本读取 `BOTHOUSE_VERSION` / `BOTHOUSE_REPO`，旧变量名仍然可用。
- **首次打开写法统一。** README 和入门指南对未签名安装包在 macOS、Windows 上首次打开的步骤写法一致。

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）（`chmod +x` 后运行）
- **校验：** `SHA256SUMS`

从 v0.1.6 起，以后的版本点左下角「更新到 vX」即可一键更新；v0.1.5 及更早的版本需要先手动下载安装这一版。网速慢时，从 v0.1.10 及更早版本一键更新仍可能超时（下载用的是旧版自带的更新程序）；遇到这种情况，请手动下载安装这一版一次。

安装包未签名。macOS 将 **Bothouse.app** 拖入 Applications，**首次打开请「右键→打开」**；Windows 若弹出 SmartScreen 提示，点「更多信息→仍要运行」。
